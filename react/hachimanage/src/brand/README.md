# HACHIMAN STUDIO 八萬工作室 品牌套件

這個資料夾是八萬工作室設計系統（HACHIMAN STUDIO 設計系統）的副本，專案裡所有頁面共用。

| 檔案 | 內容 |
| --- | --- |
| `tokens.css` | 設計系統的 tokens（顏色、間距、圓角、字級），由設計系統的 tokens.json 產生，請不要直接改 |
| `components.css` | 設計系統的共用元件（`hs-` 開頭：SiteHeader、SiteFooter、Button、Card、Notice、Tag、Field…） |
| `hachiman-lockup.png` / `hachiman-lockup-reverse.png` | 組合字標（淺色底／深色底），由定稿 `hachiman-lockup@2x.png` 等比縮成 96px 高，給 40px 高的頁首用 |
| `hachiman-icon-32.png` / `hachiman-icon-180.png` | 瀏覽器分頁圖示／iPhone 主畫面圖示 |
| `hachiman-peek.png`、`hachiman-pounce.png` | 八萬：發現問題／開始行動 |
| `orei-portrait.png` | 歐雷：安心、守護 |
| `hachiman-orei-cuddle.png` | 兩隻一起：完成、空白頁 |

- 字體：Lato＋Noto Sans TC（Google Fonts）。
- 深色主題：`<html data-theme="dark">`。
- 設計系統更新時，重新複製 `tokens.css` 與 `components.css` 即可。
